## 核心组件分析

**组件关系**
- `Connection` 结构体是核心连接管理单元
- `Transport` 接口定义了连接建立的抽象
- `Binder` 接口用于连接配置的动态绑定
- `Handler` 接口处理消息的分发

**状态管理**
- 使用 `inFlightState` 结构体跟踪连接状态
- 通过 `sync.Mutex` 保护状态变更
- 使用 `chan struct{}` 实现连接完成通知

**消息处理**
- `Reader` 和 `Writer` 接口处理消息的读写
- `Framer` 接口控制消息的编码和分帧
- `Preempter` 接口允许预处理消息

## 并发安全机制

```mermaid
flowchart TD
Start([连接初始化]) --> LockState["获取 stateMu 锁"]
LockState --> UpdateState["更新 inFlightState"]
UpdateState --> CheckIdle{"连接空闲?"}
CheckIdle --> |是| CheckShutdown{"正在关闭?"}
CheckIdle --> |否| WaitIdle["等待操作完成"]
CheckShutdown --> |是| CloseResources["关闭资源"]
CheckShutdown --> |否| ReleaseLock["释放锁"]
CloseResources --> ReleaseLock
ReleaseLock --> End([连接完成])
WaitIdle --> CheckIdle
```

**同步原语**
- `sync.Mutex`：保护 `inFlightState` 的并发访问
- `atomic.AddInt64`：原子操作序列号
- `chan struct{}`：信号通知机制
- `context.WithCancel`：请求取消机制

**关键操作**
- `updateInFlight`：原子更新连接状态
- `start`：启动读取协程
- `handleAsync`：异步处理请求
- `write`：线程安全的消息写入

## 错误传播策略

```mermaid
flowchart TD
Start([错误发生]) --> ClassifyError["分类错误类型"]
ClassifyError --> |读取错误| HandleRead["设置 readErr"]
ClassifyError --> |写入错误| HandleWrite["设置 writeErr"]
ClassifyError --> |内部错误| HandleInternal["调用 onInternalError"]
HandleRead --> CheckShutdown["检查关闭状态"]
HandleWrite --> CheckShutdown
HandleInternal --> CheckShutdown
CheckShutdown --> |可关闭| CloseConnection["关闭连接"]
CheckShutdown --> |不可关闭| ReturnError["返回错误"]
CloseConnection --> NotifyCalls["通知进行中的调用"]
NotifyCalls --> CancelRequests["取消请求"]
CancelRequests --> End([连接关闭])
ReturnError --> End
```

**错误处理机制**
- 读取错误：设置 `readErr` 并关闭连接
- 写入错误：设置 `writeErr` 并取消进行中的请求
- 内部错误：调用 `onInternalError` 回调
- 连接关闭：清理所有资源并通知完成

**错误传播**
- 通过 `updateInFlight` 统一处理状态变更
- 使用 `wait` 方法聚合错误信息
- 通过 `processResult` 处理单个请求的错误
- 利用 `context` 传播取消信号

## 连接池与资源泄漏预防

```mermaid
flowchart TD
Start([连接创建]) --> CheckPool["检查连接池"]
CheckPool --> |有可用连接| UsePooled["使用池中连接"]
CheckPool --> |无可用连接| CreateNew["创建新连接"]
CreateNew --> AddToPool["添加到连接池"]
UsePooled --> ProcessRequest["处理请求"]
AddToPool --> ProcessRequest
ProcessRequest --> CheckError["检查错误"]
CheckError --> |有错误| HandleError["处理错误"]
CheckError --> |无错误| ReturnToPool["返回连接池"]
HandleError --> CloseConnection["关闭连接"]
CloseConnection --> RemoveFromPool["从池中移除"]
ReturnToPool --> End([连接复用])
RemoveFromPool --> End
```

**资源管理**
- 使用 `sync.Once` 确保连接只关闭一次
- 通过 `defer` 语句确保资源释放
- 利用 `context` 控制连接生命周期
- 监控连接状态防止泄漏

**最佳实践**
- 及时关闭不再使用的连接
- 使用连接池复用连接
- 设置合理的超时时间
- 监控连接状态和性能
